# Automate — Windows Portable Downloads

ดาวน์โหลดโปรแกรม Automate / Rice Farming สำหรับ Windows x64

**[ดาวน์โหลดเวอร์ชันล่าสุด](https://github.com/TitiphanPong/automate-downloads/releases/latest)**

Repository นี้ใช้เผยแพร่ตัวติดตั้งและบันทึกการเปลี่ยนแปลงเท่านั้น
การใช้งานโปรแกรมต้องมี License ที่ถูกต้อง

## ติดตั้ง / อัปเดต

1. ปิดโปรแกรมเวอร์ชันเก่าก่อน
2. ไปที่ Releases แล้วดาวน์โหลดไฟล์ ZIP ของเวอร์ชันที่ต้องการ ไม่ใช่ Source code.zip
3. แตก ZIP ทั้งชุดลงโฟลเดอร์ใหม่ เช่น Desktop หรือ Documents
4. เปิด `Automate.exe` โดยเก็บ `Activation.exe`, `RiceBotWorker.exe` และ `_internal` ไว้ด้วยกัน
5. ตรวจสอบ License และค่าตั้งก่อนเริ่มใช้งาน ไม่ต้องติดตั้ง Python หรือฟอนต์เพิ่ม

ถ้าเคยปรับค่าตั้งเอง ให้สำรองไฟล์เดิมแล้วเทียบกับไฟล์รุ่นใหม่ก่อนย้ายค่า
เก็บเวอร์ชันเก่าไว้ย้อนกลับได้ แต่ไม่ควรเปิดสองเวอร์ชันทำงานพร้อมกัน

## โหมดที่รองรับ

- Rice Farming + AutoTrunk
- AutoTrunk Rice
- Pork Processing
- Pork Packing

LIVE เริ่มในสถานะพัก กด F6 เพื่อเริ่ม/พัก และ F8 เพื่อหยุดฉุกเฉิน
ใช้งานเฉพาะในสภาพแวดล้อมที่อนุญาต

แต่ละ Release มีไฟล์ `.sha256` สำหรับตรวจสอบความครบถ้วนของ ZIP
